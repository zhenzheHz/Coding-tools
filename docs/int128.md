# 128-bit Integers

## Include and use

Include `<bits/stdc++.h>` before the library. The extensionless header
`<int128>` includes `int128.hpp`.

```cpp
#include <bits/stdc++.h>
#include <int128>

int main() {
    zz_library::i128 product = static_cast<zz_library::i128>(1'000'000'000'000LL)
                             * 1'000'000'000'000LL;
    zz_library::u128 count;
    std::cin >> count;
    std::cout << product << ' ' << count << '\n';
}
```

## Types and namespace

The header defines `zz_library::i128` as `__int128_t` and `zz_library::u128`
as `__uint128_t`. These are compiler extensions, not standard C++ types, and
require compiler support for `__int128_t` and `__uint128_t`.

## Stream operators

Insertion and extraction operators are defined in the global namespace so
ordinary stream expressions can find them. They read and write decimal values
across each type's full range, including the signed minimum and unsigned
maximum.

| Expression | Behavior |
| --- | --- |
| `std::cout << value` | Print an `i128` or `u128` as decimal digits. |
| `std::cin >> i128` | Parse an optional `+` or `-` sign and decimal digits; set `failbit` for invalid or out-of-range input. |
| `std::cin >> u128` | Parse optional `+` and decimal digits; negative input, invalid text, or overflow sets `failbit`. |

The header does not provide `std::to_string` overloads. Use stream output for
formatting these types.
