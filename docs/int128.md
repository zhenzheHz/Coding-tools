# 128-bit Integers

## Include and use

Include `<bits/stdc++.h>` before the library. The extensionless header
`<int128>` includes `int128.hpp`.

```cpp
#include <bits/stdc++.h>
#include <int128>

int main() {
    zz_library::i128 product = static_cast<zz_library::i128>(1'000'000'000'000LL)
                             * 1'000'000'000'000LL;
    zz_library::u128 count = 1;
    std::cout << product << ' ' << count << '\n';
}
```

The header defines `zz_library::i128` as the signed compiler-provided 128-bit
integer type and `zz_library::u128` as its unsigned counterpart. Stream
insertion writes their decimal representation to `std::ostream`, including
the full range of unsigned values and the signed minimum value.

These types are compiler extensions, not standard C++ types, and require a
compiler with `__int128_t` and `__uint128_t` support. The header provides
stream output only; standard stream input and `std::to_string` overloads are
not provided.
